# 1. Modular Multiplicative Inverse
```
a / b == a * (1 / b)
=> (a / b) % p == (a * inverse of b) % p

```
```
(modular multiplicative inverse of b)
=> b^(-1) s.t. (b * b ^ (-1)) % p == 1
```
## 1-1. Example 1: when p == 7
```
(3 * 5) % 7 == 15 % 7
            == 1
=> (inverse of 3) == 5
```

## 1-2. Example 2: (10 / 2) % 7 == ?
```
(2 * 4 == 8, 8 % 7 == 1)
=> (inverse of 2) is 4
=> (10 * 4) % 7 == 5
```

# 2. Fermat's Little Theorem
> (Condition) p is prime and a is not a multiple of p:
- `a^(p-1) ≡ 1 (mod p)` <br>
=> `a^(p-2) ≡ a^(-1) (mod p)`

Therefore <br>
`a^(p-2) ≡ a^(-1) (mod p)`

<br>

```java
public class ModularInverse {
    static final int MOD = 1000000007;  // the prime usually given in problems
    
    // compute the inverse with fast exponentiation
    static long power(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        
        while (exp > 0) {
            if (exp % 2 == 1) {
                result = (result * base) % mod;
            }
            base = (base * base) % mod;
            exp /= 2;
        }
        return result;
    }
    
    // compute the inverse with Fermat's little theorem
    static long modInverse(long a, long mod) {
        return power(a, mod - 2, mod);
    }
    
    // modular division
    static long modDivide(long a, long b, long mod) {
        return (a * modInverse(b, mod)) % mod;
    }
}
```
